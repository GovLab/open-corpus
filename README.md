## Record fields

Every entry in `data/sources.json` has `id`, `program`, `type`, `title` and `url`, and where known `date`, `summary` (the teaser shown on the page itself), `authors`, `topics`, `series`, `languages`, `video_url` (the workshop recording) and `duration_min`.

## About this catalog

This catalog is generated from the search index behind rebootdemocracy.ai and innovate-us.org, and every link is checked before it is listed (`scripts/export-urls.mjs`, `scripts/check-links.mjs`, then `scripts/build-readme.mjs`). It holds links, short teasers taken from the pages themselves, and metadata; please cite the linked pages. Spotted an error? Open an issue.
