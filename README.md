# Open Corpus: Reboot Democracy and InnovateUS

An open, machine-readable index of content from Reboot Democracy (rebootdemocracy.ai) and InnovateUS (innovate-us.org): blog posts, weekly news digests, workshops, workshop recordings and courses. Every entry links to the original page.

The catalog (`data/sources.json`, `data/sources.csv`, `lists/` and `llms.txt`) is generated by `scripts/export-urls.mjs` and `scripts/build-readme.mjs` and will appear here after the first export. See [MAINTAINING.md](MAINTAINING.md).
